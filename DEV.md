# Development Setup Guide

## Quick Start

### 1. Install dependencies
```bash
npm install
```

### 2. Set up environment variables

Create a `.env.local` file in the root directory (gitignored, not committed):

```bash
# Database (from Neon)
DATABASE_URL=postgresql://user:password@host:5432/database?sslmode=require

# Auth (from Neon Auth settings)
VITE_NEON_AUTH_URL=https://your-project.neonauth.region.aws.neon.tech/database/auth

# Session secret
AUTH_SECRET=your-random-secret-here

# Deployment URL (for magic link generation)
BASE_URL=http://localhost:3001
```

### 3. Run dev servers (backend + frontend together)

```bash
npm run dev
```

This starts:
- **Backend (Express)**: `http://localhost:3001` — handles magic link auth, database, API routes
- **Frontend (Vite)**: `http://localhost:5173` — React UI

### 4. Test the magic link flow

1. Navigate to `http://localhost:5173/first-time-login`
2. Enter an email address
3. Check the **server terminal** for the magic link (logged as `[DEV] Magic link for...`)
4. Copy the link and visit it to verify and sign in

## Database & Auth Flow

### Database (Neon PostgreSQL)
- **Users table**: email, password_hash, role, created_at
- **User profiles table**: display_name, bio, interests, member_status
- **Magic links table**: token, email, verified, expires_at (24h)
- **Posts table**: article content

### Auth Flow
1. User enters email on `/first-time-login`
2. `POST /api/auth/magic-link` creates a token and sends link
3. User clicks link in email → `/auth/verify?token=...`
4. `POST /api/auth/verify-link` verifies token and signs in user
5. User is redirected to `/dashboard`
6. First-time users auto-get a profile created

### Role System
- **user**: Default (public browsing)
- **authed_user**: Signed-in members (can comment, edit profile)
- **mod**: Moderators (access `/mod` page)
- **admin**: Admins (access `/admin` page, can manage users)

## Deployment to Netlify

### 1. Push code to GitHub
```bash
git add .
git commit -m "Your message"
git push origin main
```

### 2. Connect to Netlify
- Go to [netlify.com](https://netlify.com)
- Click "New site from Git"
- Select your GitHub repo (`redmasterf0x/starcast`)
- Netlify auto-detects the `netlify.toml` config

### 3. Set environment variables in Netlify dashboard
- Go to **Site settings** → **Environment**
- Add your production env vars:
  - `DATABASE_URL` (Neon connection string)
  - `VITE_NEON_AUTH_URL` (Neon Auth endpoint)
  - `AUTH_SECRET` (random secret)
  - `BASE_URL=https://starcastonline.netlify.app` (your deployed URL)

### 4. Deploy
- Netlify auto-deploys when you push
- Your app is live at `https://starcastonline.netlify.app`

## Debugging

### Backend issues?
- Check server terminal output for database errors
- Verify `DATABASE_URL` and `VITE_NEON_AUTH_URL` are set
- Magic links are logged to console in dev: `[DEV] Magic link for...`

### Frontend issues?
- Check browser console (F12) for errors
- Verify the Vite server is running on port 5173
- Clear browser cache if styles/JS don't update

### API not responding?
- Make sure backend is running (`npm run start` or `npm run dev`)
- Check that `BASE_URL` matches your deployment domain (localhost:3001 for dev)
